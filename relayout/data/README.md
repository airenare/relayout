# Word lists

`en.txt.gz` and `ru.txt.gz` are derived from
[hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
(OpenSubtitles 2018 frequency lists), filtered and normalised by
`scripts/build-wordlists.py`. They are licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); the rest of
relayout is MIT.
